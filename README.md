# InvestMitra frontend

React 18 single-page app for InvestMitra, a paper-trading simulator for the NIFTY 500 (pretend money, real lessons).
Newsprint-style UI: markets search, folios, trade slip with printed-receipt animations, watchlist, price desk.

```bash
npm install
npm start          # http://localhost:3000, expects the backend on http://localhost:8080
```

Set `REACT_APP_API_URL` to point at a different backend. Full documentation lives in [`knowledge/`](knowledge/).
